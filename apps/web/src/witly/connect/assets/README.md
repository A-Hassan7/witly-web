# Platform brand marks

Real, first-party brand logos used in the "Connect a chat app" picker. Each file
was downloaded from the source below and is rendered via `@svgr/webpack` (the
`Icon` named export) in [`../brandIcons.tsx`](../brandIcons.tsx).

| File | Source | Notes |
|---|---|---|
| `whatsapp.svg` | Wikimedia Commons — `WhatsApp.svg` | Official green speech-bubble mark |
| `instagram.svg` | Wikimedia Commons — `Instagram_logo_2016.svg` | Full-colour gradient glyph |
| `messenger.svg` | Wikimedia Commons — `Facebook_Messenger_logo_2020.svg` | Full-colour radial-gradient bubble |
| `discord.svg` | simple-icons (`discord.svg`) | Official Clyde mark; `fill` set to Discord Blurple `#5865F2` |

These are third-party trademarks used only to identify the corresponding service.
Do not alter the marks beyond scaling. Replace a file here to swap an icon — no
code change needed as long as the filename stays the same.
